## 🔹 Task 3: Secure Coding Review

### Overview
A Python-based login application was developed using SQLite and reviewed for common security issues.

### Technologies & Tools
- Python
- SQLite
- Visual Studio Code
- Bandit

### Key Activities
- Created a basic username-based login application.
- Connected the application with an SQLite database.
- Tested the login functionality.
- Performed a security review of the Python code.
- Used Bandit for automated security analysis.
- Identified a security issue related to SQL query construction.
- Reviewed the security finding and considered appropriate improvements.

### Security Analysis
Bandit was used to scan the Python source code for potential security issues. The scan identified a **CWE-89 SQL-related finding** associated with the SQL expression in the application.

### Learning Outcome
This task provided practical experience with secure coding, database interaction, vulnerability identification, and basic static security analysis using Bandit.
